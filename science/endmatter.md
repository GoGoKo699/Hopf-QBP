# Data and code availability

<a id="Sx1.p1.1"></a>

No external datasets were used in this work. The Hopf-QBP repository [[42](../references/paper-bibliography.md#bib.bib22)] provides independent NumPy reference implementations and Qibo [[43](../references/paper-bibliography.md#bib.bib21)] circuit builders and decoders, together with deterministic tests supported by continuous integration. The repository also contains the direct-angle assigned Hopf CNOT ledger, exact-recompilation and statistical analyses, and readout checks. The accompanying reproducibility instructions describe how to run the implementations and associated checks. Circuit checks were performed using exact Qibo output distributions.

# Generative AI disclosure

This paper began in a midnight conversation between the first author and OpenAI’s ChatGPT, using GPT-5.5 Pro and GPT-5.6 Pro, and developed through many rounds of conjecture, calculation, criticism, and revision. ChatGPT assisted in exploring constructions, developing arguments, checking implementations, and shaping the manuscript. GPT-6 was also used during the final revision phase. The dialogue served as a working blackboard: ideas were tested, discarded, or rebuilt as the mathematics required. The first author chose the questions, set the scope, selected the paths, and verified the final results. All authors reviewed the arguments, calculations, implementations, and manuscript and accept responsibility.
