# I Introduction

Variational quantum algorithms optimize a scalar objective by changing many control parameters in a state-preparation circuit. A selected derivative describes the response along one control, whereas a model update may require the complete vector. When separate measurement procedures are used for separate coordinates, much of the state preparation and objective evaluation is repeated. The task studied here is to use the structure of the state coordinates to make one quantum outcome informative about many derivatives at once.

<a id="S1.p2.1"></a>

The Hopf ansatz provides that structure [[1](../references/paper-bibliography.md#bib.bib6)]. It constructs computational-basis amplitudes through nested two-way splits: one angle distributes amplitude between two groups of basis states, and later splits refine each group. These splits form a balanced binary tree. Each magnitude coordinate is the physical rotation angle at its designated split, while each complex leaf phase is programmed directly. This one-coordinate–one-angle correspondence keeps the state representation, inverse coordinates, local geometry, and counted circuit controls in a common language rather than treating the state as the output of an arbitrary compiler.

<a id="S1.p3.1"></a>

Ref. [[1](../references/paper-bibliography.md#bib.bib6)] supplied direct-angle circuits for every normalized real or complex pure state, a classical inverse that recovers coordinates from known amplitudes, and a diagonal metric with normalized coordinate directions. Indexed tangent and signed-branch state preparations also made one selected derivative accessible. Together, these capabilities place state preparation, objective evaluation, and coordinate updates in one variational loop [[2](../references/paper-bibliography.md#bib.bib23)]. The present construction extends that indexed interface to collective readout: it compiles the normalized magnitude directions into computationally addressed columns and uses their common objective response to produce a shared finite-shot record.

At a fixed Hopf parameter point, the requested output is the complete classical vector of raw coordinate derivatives of a scalar expectation. For $`n`$ qubits and $`N=2^{n}`$, the real and complex charts have $`M=N-1`$ and $`M=2N-1`$ real-valued parameters, respectively, so the output grows exponentially with $`n`$. The objective is assumed to admit a controlled reflection with known relative phase. This coherent access keeps the state and its reflected image in two branches whose interference exposes the transition moments needed for differentiation.

The addressed Hopf frame is a reversible basis change with the prepared state in its zero column and each normalized magnitude direction in a distinct labeled column. After the controlled reflection, the inverse frame transfers the relevant transition moments to those labels. Measuring the ancilla and system in $`X`$ produces one bit string whose parities supply signed samples for every magnitude direction. The samples decoded from one outcome are correlated, but each complete depth record has fixed Euclidean norm. A signed histogram and a single Walsh–Hadamard transform evaluate all the parity averages in a classical batch.

The complex construction retains this magnitude record after dressing the frame with the leaf phases. Phase derivatives are already localized in the computational basis, so a separate signed leaf record supplies the phase block without an inverse frame. For selected-depth access, the checkpoint construction reverses only the suffix below one chosen depth; the measured prefix identifies the derivative within that layer. The global frame is the principal collective construction. Checkpointing trades cross-depth record reuse for a shorter, layer-local reverse circuit.

Every magnitude-depth record has norm two, independently of its width. Vector concentration therefore controls all coordinates at a depth without a coordinatewise union bound; only the $`n`$ depth-level failure events need to be combined. For simultaneous additive coordinate accuracy $`\varepsilon`$ and confidence $`1-\delta`$, sufficient execution counts are

<a id="S1.EGx1"></a>

```math
\begin{aligned}S_{\mathrm{glob}} & =\mathcal{O}\!\left(\frac{1+\log(n/\delta)}{\varepsilon^{2}}\right),\end{aligned}
```

```math
\begin{aligned}S_{\mathrm{chk}} & =\mathcal{O}\!\left(\frac{n\{1+\log(n/\delta)\}}{\varepsilon^{2}}\right).\end{aligned}
```

At fixed accuracy and confidence, these become $`\mathcal{O}(\log\log M)`$ and $`\mathcal{O}(\log M\log\log M)`$ independent executions. The saving comes from reusing each global record across depths; the classical output still contains $`M`$ entries.

<a id="S1.p8.1"></a>

The resource analysis counts controlled-reflection calls, assigned Hopf CNOT work, classical decoding, and storage separately. The matched comparison follows Ref. [[3](../references/paper-bibliography.md#bib.bib1)], with the logarithmic structured-circuit scale of Ref. [[4](../references/paper-bibliography.md#bib.bib7)] as the benchmark. Under the designated direct-angle schedules, the global method has $`\mathcal{O}(M\log M\log\log M)`$ assigned Hopf work and meets this benchmark relative to a scalar evaluation using the same forward circuit and controlled reflection. Walsh decoding costs $`\mathcal{O}(M\log M)`$. These guarantees concern absolute raw-coordinate accuracy; relative or directional guarantees depend on a nonzero gradient signal, and metric-rescaled outputs have additional conditioning requirements.

<a id="S1.p9.1"></a>

Existing gradient methods address different combinations of access and output. Parameter shift and other low-depth rules commonly obtain selected coordinate derivatives from ordinary objective evaluations [[5](../references/paper-bibliography.md#bib.bib43), [6](../references/paper-bibliography.md#bib.bib9), [7](../references/paper-bibliography.md#bib.bib10), [8](../references/paper-bibliography.md#bib.bib11), [9](../references/paper-bibliography.md#bib.bib44)]. Classical simulator adjoints instead reverse a stored simulation [[10](../references/paper-bibliography.md#bib.bib12)]. Other quantum methods reuse measurements through coherent parameter registers, commutation, algebraic structure, generalized Hadamard tests, stabilizer descriptions, or classical-shadow measurements [[11](../references/paper-bibliography.md#bib.bib17), [4](../references/paper-bibliography.md#bib.bib7), [12](../references/paper-bibliography.md#bib.bib13), [13](../references/paper-bibliography.md#bib.bib45), [14](../references/paper-bibliography.md#bib.bib14), [15](../references/paper-bibliography.md#bib.bib15), [16](../references/paper-bibliography.md#bib.bib18), [17](../references/paper-bibliography.md#bib.bib20)]. Random-direction methods return stochastic search information whose variance and optimizer role differ from those of a uniformly accurate materialized vector [[18](../references/paper-bibliography.md#bib.bib46), [19](../references/paper-bibliography.md#bib.bib19)]. These approaches are not totally ordered. Hopf-QBP combines the stronger controlled-reflection interface with an addressed differential frame, allowing every global outcome to contribute to the complete raw magnitude-coordinate vector. Its reverse organization also connects to classical backpropagation, adjoint control, and checkpointed computation [[20](../references/paper-bibliography.md#bib.bib38), [21](../references/paper-bibliography.md#bib.bib39), [22](../references/paper-bibliography.md#bib.bib41), [23](../references/paper-bibliography.md#bib.bib40)].

<a id="S1.p10.1"></a>

The resulting interface may be useful when complete state-coordinate updates are needed and the objective admits an efficient controlled Pauli or reflection description. In variational scientific computing, such settings include deflation, simulation, process approximation, linear systems, and differential equations [[24](../references/paper-bibliography.md#bib.bib31), [25](../references/paper-bibliography.md#bib.bib33), [26](../references/paper-bibliography.md#bib.bib34), [27](../references/paper-bibliography.md#bib.bib26), [28](../references/paper-bibliography.md#bib.bib27), [29](../references/paper-bibliography.md#bib.bib28)]. Potential quantum-machine-learning uses include trainable embeddings, metric learning, kernel alignment, generator updates against fixed binary discriminators, and fidelity-trained pure-state models [[30](../references/paper-bibliography.md#bib.bib24), [31](../references/paper-bibliography.md#bib.bib30), [32](../references/paper-bibliography.md#bib.bib25), [33](../references/paper-bibliography.md#bib.bib32), [34](../references/paper-bibliography.md#bib.bib29)]. Sensing and discrimination may use the same interface to optimize probes, sensor networks, and binary tests [[35](../references/paper-bibliography.md#bib.bib35), [36](../references/paper-bibliography.md#bib.bib36), [37](../references/paper-bibliography.md#bib.bib37)]. Checkpoint records may also support layer-local quantum-control updates when the control decomposition follows the Hopf-tree depth. In each setting, the data map, controlled-reflection compiler, aggregation rule, and optimizer remain application-specific; the result here supplies the coordinate-gradient interface rather than a complete application algorithm.
